So first of all let you know that computer does not speak normal human language it has its own machine language which we called as binary language and which has only 0 and 1 so to talk to computer we need something that can converts our language into computer's language and that thing is known as 'Compiler'.

- Python is programming/scripting language.

## Programming languages purpose

To create applications
- C, Java

## Scripting languages purpose

To do automations and control existing software
- JavaScript, Python

## Markup languages purpose

To give structure to the content
- They print as it is visually
- For e.g.: when you write 2+2 in markup language then it will not print 4 but it will paste as it is 2+2
- HTML

## Style sheet languages purpose

To enhance appearance
- CSS

## Query languages purpose

To deal with database
- SQL

## Shell languages purpose

To give command to operating systems
- BASH

## Configuration languages purpose

To tell software how to behave
- JSON
