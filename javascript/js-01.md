## Variables and Declarations

- Variables are basically containers that hold data and also change it later if you want
- In JS the keywords to create them are : `var`, `let` and `const`

### var

1. **Old and risky**, because suppose you created a variable

   ```js
   var a = 12;
   var a = 14;
   ```

   - now its valid in var, JS will not throw any error
   - so basically it can be redeclared, what does redeclared means is you are basically making same variable again even once it is made
   - also it can be reassigned, which is okay because you can reassign the value if you want

     ```js
     var a = 13;
     a = 45;
     ```

   - so in short difference between redeclaration and reassigning is in redeclaration you are making a same named variable again where as in reassigning you are just changing the inside value of the variable just like in real life you put different thing in your container and now you know that new thing is in that container and for redeclaration you are buying second container with same label 

2. **var is hoisted to the top with undefined value**, what it means
   - suppose you said

     ```js
     console.log(a)
     var a = 14;
     ```
     now basically you are saying to print or say show the value of variable a even before you created it but JS will not throw any error instead it will say undefined.

   - so basically what's happening is `var a = 14;` breaks in two parts where first part `var a = undefined;` goes on top and other part `a = 14;` remains at the line where it was written by the user and therefore according to that `console.log(a)` is printing / showing the value of variable a as undefined
