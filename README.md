# My Notes

This is my personal notes repo as I learn to code - written in my own words as I watch tutorials, read docs, and figure things out.

I'm keeping this public mainly to stay consistent and track my own progress, but if it helps anyone else, even better.

## Structure

Notes are organized by topic, with one Markdown file per concept:

```
learning-notes/
└── programming-basics/
    └── programming-languages.md
└── javascript/
    └── js-01.md
└── cs50-notes/
    └── lecture-0.md
    └── lecture-1.md
```
